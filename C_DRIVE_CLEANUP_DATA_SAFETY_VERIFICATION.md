### Operation 2.6: Compact WSL2 VHDX

**Command:** Stop Docker, run `Optimize-VHD -Path $vhdxPath -Mode Full`, restart Docker

#### Safety Verification
⚠️ **CAUTION** - Requires stopping Docker Desktop temporarily  
✅ **SAFE** - Only compacts virtual disk, does not delete data  
✅ **SAFE** - All containers will restart automatically  
✅ **SAFE** - Does NOT delete active volumes  
✅ **SAFE** - Does NOT affect database data  
✅ **SAFE** - Does NOT affect project data  

**Technical Explanation:**  
- `Optimize-VHD` compacts the virtual disk by removing unused space
- All data (containers, volumes, images) is preserved
- Docker Desktop must be stopped temporarily to access the VHDX file
- After optimization, Docker Desktop restarts and containers resume

#### Risk Assessment
**Risk Level:** 🟡 MODERATE  
**Impact:** Temporary service interruption (~5-10 minutes)  

#### Pre-Execution Checks
- [ ] **CRITICAL:** Verify all 8 containers are running: `docker ps`
- [ ] **CRITICAL:** Verify database connectivity: `docker exec postgres pg_isready -U postgres`
- [ ] **CRITICAL:** Create database backup (recommended)
- [ ] Verify no critical operations in progress
- [ ] Confirm maintenance window availability

#### Post-Execution Verification
- [ ] Verify Docker Desktop started successfully
- [ ] Verify all 8 containers are running: `docker ps`
- [ ] Verify database connectivity: `docker exec postgres pg_isready -U postgres`
- [ ] Verify Redis connectivity: `docker exec redis redis-cli ping`
- [ ] Verify application functionality
- [ ] Check VHDX size reduction

#### Rollback Procedure
**Available:** If containers fail to start after VHDX optimization:

1. Restart Docker Desktop:
```powershell
Stop-Process -Name "Docker Desktop" -Force
Start-Sleep -Seconds 5
Start-Process "C:\Program Files\Docker\Docker\Docker Desktop.exe"
```

2. Check container logs:
```powershell
docker logs <container_name>
```

3. Restart individual containers:
```powershell
docker start <container_name>
```

4. If issues persist, restore from backup

**Note:** VHDX optimization is reversible in the sense that the VHDX will grow again as data is added. No data is lost during optimization.
